# Events Editor

The Events Editor exposes individual trace events in timestamp order. It is
useful when a summary view shows a suspicious interval and the analyst needs to
inspect the raw events around it.

Use the Events Editor to validate context, search for nearby scheduler events,
inspect syscall entry and exit, and avoid over-interpreting aggregated views.
