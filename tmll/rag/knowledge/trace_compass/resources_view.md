# Resources view

The Resources view shows system resources such as CPUs and interrupts over
time. It helps compare a thread delay with CPU activity and interrupt behavior
around the same interval.

Use it when deciding whether the system looked CPU-saturated or idle while a
thread was blocked or runnable. It complements thread-level evidence rather
than replacing it.
