# Latency views

Trace Compass latency views present distributions and tables for measured
latency segments. They can help identify long-tail delays and compare latency
by type.

For syscall latency, use latency views to find long syscalls, then correlate
those segments with thread state intervals before drawing root-cause
conclusions.
